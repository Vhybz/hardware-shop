# Adom Mmoroso ENT. POS

Adom Mmoroso ENT. Point of Sale and Inventory Management System (Building Materials & Hardware).

## Features

- **Inventory Control**: Real-time product tracking, building materials categorisation, and barcode support.
- **Point of Sale (POS)**: Fast checkout, digital receipts, debt/credit sales tracking.
- **Multi-Branch Management**: Seamless multi-branch operations and offline-first data sync.
- **Sales Analytics**: Sales, expenses, debt collection, and profit reports.
- **SMS Notifications**: Automated customer receipts, debt reminders, and staff onboarding alerts.

## Getting Started

This project is built with Flutter and Riverpod.

- Ensure Flutter SDK (^3.11.5 or above) is installed.
- Run `flutter pub get` to download dependencies.
- Run `flutter run` to start the application.
